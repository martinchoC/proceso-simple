Manual de usuario: Jurisdicciones

Los organismos o territorios que cobran impuestos (Nación, cada provincia para Ingresos Brutos, municipios), usados en la configuración de impuestos y en los datos de IIBB de clientes y proveedores.

La pantalla principal

ColumnaQué muestra
ID / Código / NombreIdentificación de la jurisdicción.
TipoNacional, Provincial, Municipal o Convenio Multilateral (ver Tipos de Jurisdicción).
País / Provincia / LocalidadUbicación geográfica, si se cargó.
Organismo RecaudadorPor ejemplo ARBA o AGIP.
Requiere PadrónSi las alícuotas se toman del padrón de contribuyentes del organismo.
Estado / AccionesActiva o Inactiva, y sus botones.

Tiene buscador, recarga ↻ y menú Exportar.

Agregar o editar una jurisdicción

CampoPara qué sirve
Código *Hasta 10 caracteres.
Nombre *Hasta 100 caracteres.
Tipo de Jurisdicción *Nacional, Provincial, etc.
País / Provincia / LocalidadOpcionales. La lista de provincias depende del país elegido y la de localidades, de la provincia.
Organismo RecaudadorOpcional.
Código ExternoOpcional: código usado por el organismo o por otros sistemas (hasta 20 caracteres).
Requiere PadrónActivalo si esta jurisdicción trabaja con padrón de alícuotas por contribuyente.
OrdenOrden de aparición.

Si falta el tipo, el sistema avisa "Debe seleccionar un tipo de jurisdicción".

Botones disponibles

BotónQué haceCuándo aparece
