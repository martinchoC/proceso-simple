Emisión del Volante de Pago

En modules/sindicatos/volantes.php el empleador selecciona las deudas de DDJJ pendientes y genera el volante de pago correspondiente. El volante agrupa los conceptos devengados y proyecta los recargos por mora.

Cálculo de Intereses a Dos Fechas

Cálculo Automático por Tramo de Tasa:

El sistema toma la tasa mensual de interés resarcitorio (tasas_interes.php) vigente para cada período de mora y calcula el importe exacto a pagar a dos fechas alternativas:

  • 1° Vencimiento: Importe a pagar dentro de los próximos días hábiles.
  • 2° Vencimiento: Importe con el interés adicional acumulado hasta una segunda fecha posterior.

Código de Barras Banco Nación (Code128)

El comprobante impreso en PDF incluye una línea de código de barras estándar Code128 que contiene: código de ente (869955555), número de sociedad, ID de volante, fecha de vencimiento y monto exacto en centavos para lectura óptica en ventanilla bancaria.

Canales Electrónicos: Red Link e Interbanking

Al confirmarse el volante, el sistema publica la deuda en tiempo real:

  • Red Link (SOAP): Disponible de inmediato en Home Banking para pago de servicios con el código de link del empleador.
  • Interbanking (API REST): Publicación para pago corporativo entre cuentas bancarias empresariales.

Preguntas frecuentes

Consulta Respuesta
¿Qué pasa si vencieron las dos fechas del volante? El volante caduca y los canales de cobro rechazan el pago. El empleador debe generar un nuevo volante con fechas actualizadas e intereses recalculados.
