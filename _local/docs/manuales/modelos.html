Manual de usuario: Modelos

Los modelos de cada marca (por ejemplo Ford → Ranger), usados para indicar la compatibilidad de los productos.

Cada modelo pertenece a una Marca, y puede tener Submodelos. Para cargar un modelo, su marca tiene que existir antes.

La pantalla principal

El listado muestra ID, Nombre del Modelo, Marca, Estado (los inactivos en gris) y Acciones, con buscador y botón ↻ de recarga.

Agregar o editar un modelo

CampoPara qué sirve
Marca *Marca a la que pertenece el modelo.
Nombre del Modelo *Hasta 100 caracteres.

Al guardar aparece "Modelo guardado correctamente". Errores posibles: "Debe seleccionar una marca válida", "Ya existe un modelo con este nombre en la marca seleccionada".

Para ver cuántos productos tiene cada modelo, o dar de baja de una vez los modelos sin productos, usá la pantalla Submodelos (pestañas Jerárquico y Dashboard).
