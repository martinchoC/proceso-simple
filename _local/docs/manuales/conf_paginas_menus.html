Estructura del Menú Lateral (Árbol con padre_id)

En paginas.php se gestionan todas las pantallas que integran el sistema:

  • Nivel 1 (Secciones o Carpetas): Páginas con padre_id = 0 (por ejemplo: Ventas, Compras, Tesorería, Stock). Agrupan opciones pero no abren pantallas directamente.
  • Nivel 2 (Pantallas Operativas): Páginas cuyo padre_id apunta a una sección de nivel 1. Contienen la URL física del archivo PHP ejecutable.

Atributos de una Página

Atributo Función
Nombre Etiqueta visible en el menú lateral.
URL Ruta relativa del archivo (ejemplo: ventas_facturas.php).
Orden Número que define la posición de aparición de arriba hacia abajo.
Requiere Bienes Si vale 1, la opción se oculta automáticamente si la empresa activa es de tipo Servicios.

Accesos Directos Superiores

Marcando una página como es_acceso_directo = 1 y asignándole un ícono en orden_acceso_directo, el sistema proyecta un botón rápido con tooltip en la barra superior de la aplicación para navegación inmediata.

Catálogo de Íconos

En iconos.php se mantiene la librería de clases Bootstrap Icons (bi bi-cart, bi bi-cash-stack, bi bi-boxes) disponibles para asignar a cada menú y botón.

Preguntas frecuentes

Consulta Respuesta
¿Por qué una carpeta del menú aparece vacía para un usuario? Si el perfil del usuario no tiene permisos en ninguna de las páginas hijas de una sección, el sistema oculta la carpeta completa automáticamente.
