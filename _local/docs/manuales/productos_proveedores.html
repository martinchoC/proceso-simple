¿Para qué sirve?

Cada proveedor identifica los productos con su propio código, distinto del tuyo. Esta pantalla guarda esa correspondencia: "mi producto X es el código 1234 del proveedor A y el código AB-77 del proveedor B". Ese vínculo se usa en:

  • Órdenes de Compra y Facturas de Proveedores: el buscador de productos encuentra por código del proveedor y muestra primero los productos vinculados.
  • Lista Precios Proveedores: al importar el Excel del proveedor, cada código se busca acá para saber a qué producto tuyo le corresponde el precio.
  • El buscador general de Productos, que también encuentra por código de proveedor.

También se crean vínculos desde las órdenes y facturas (opción "Vincular y usar", o al crear un producto rápido) y desde Lista Precios Proveedores al cargar el precio de un producto que todavía no estaba vinculado. Todos aparecen acá.

Buscar y filtrar

  • "Buscar por código, nombre o código de proveedor...": busca mientras escribís.
  • Todos los proveedores: muestra solo los productos vinculados a un proveedor.
  • Todos los productos / Con proveedor vinculado / Sin proveedor vinculado: útil para encontrar productos a los que les falta el vínculo.
  • Marca → Modelo → Submodelo: filtra por compatibilidad. Cada uno se habilita al elegir el anterior.

Vincular un proveedor a un producto

  1. Tocá + en la fila del producto. Se abre "Vincular proveedor" con el nombre del producto.
  2. Elegí el Proveedor (obligatorio; si falta, avisa "Falta el proveedor").
  3. Escribí el Código de proveedor (hasta 50 caracteres).
  4. Tocá Guardar. Aparece "¡Vinculado!".

Si ese proveedor ya está vinculado al producto, el sistema avisa "Este proveedor ya está vinculado (activo) a este producto". Si el vínculo existía pero se había quitado, se vuelve a activar ("Vínculo reactivado correctamente").

Cargá el código tal como figura en la lista de precios del proveedor. Si no coincide, la importación de su lista no va a encontrar el producto.

Cambiar el código de proveedor

Tocá el lápiz ✎ de la etiqueta. Se abre "Editar código de (proveedor)" con el código actual. Cambialo y tocá Guardar. Aparece "¡Actualizado!". Usalo cuando el proveedor cambió el código de un producto (la importación de su lista te lo indica con un "Posible código nuevo").

Quitar un vínculo

Tocá la ✕ de la etiqueta. Después de una confirmación ("¿Quitar vínculo?"), el vínculo se da de baja y aparece "¡Quitado!". El producto deja de aparecer como vinculado a ese proveedor y su código ya no se reconoce al importar la lista. Si lo necesitás de nuevo, volvé a vincularlo con +.

Pestaña Dashboard

Muestra el grado de avance de la carga de vínculos:

  • Indicadores: Productos activos, Con proveedor vinculado, Sin vincular y Correlación (% de productos con al menos un proveedor; en verde desde 75%, en amarillo desde 40%, en rojo por debajo).
  • Top 10 proveedores por cantidad de productos vinculados.
  • Correlación por marca: % de productos vinculados en las 10 marcas con más productos.
  • Proveedores sin ningún producto vinculado, con su CUIT.

Exportar

Arriba a la derecha: ↻ recarga la tabla, y los botones de Excel y PDF exportan el listado.

Preguntas frecuentes

PreguntaRespuesta
Importé la lista de un proveedor y un producto quedó como "no vinculado". Buscá el producto acá y vinculalo a ese proveedor con el código exacto que trae el Excel. Después volvé a importar.
¿Un producto puede tener varios proveedores? Sí, uno por cada proveedor, cada uno con su código.
Veo un vínculo "(sin código)". ¿Por qué? Se creó sin código; por ejemplo, al cargar a mano en Lista Precios Proveedores el precio de un producto que todavía no estaba vinculado. Completalo con el lápiz ✎ para que la importación lo reconozca.
