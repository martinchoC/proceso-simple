¿Para qué sirve?

Una configuración de impuesto une un tipo de impuesto con su forma de cálculo y con los comprobantes donde corresponde. Hoy el sistema la usa al cargar Facturas de Proveedores: allí se ofrecen las percepciones configuradas para el subgrupo de ese comprobante, y al confirmar la factura el importe va a la cuenta contable indicada acá.

La pantalla principal

Columnas: ID, Tipo de Impuesto, Jurisdicción, Cuenta Contable, Tipo Cálculo, Aplica Siempre, Prioridad, Vigencia Desde, Vigencia Hasta, Estado y Acciones. Tiene buscador, recarga ↻ y menú Exportar.

+ Agregar abre la ventana Configuración de Impuesto, con tres pestañas. El lápiz de una fila la abre para editar.

Pestaña Configuración General

CampoPara qué sirve
Tipo de Impuesto *Cuál impuesto se configura.
JurisdicciónOpcional: organismo o provincia (ver Jurisdicciones).
Cuenta ContableOpcional, pero necesaria para que el asiento de la factura pueda registrar el impuesto.
Tipo de Cálculo *Manual (alícuota fija), Padrón (alícuota según el padrón de la jurisdicción) o Regla (fórmula personalizada).
PrioridadOrden en que se aplican los impuestos.
Vigencia Desde *Desde cuándo rige.
Vigencia HastaOpcional: hasta cuándo rige.
Aplica siempreViene marcado: se aplica sin validaciones adicionales.

Tocá Guardar Configuración. Aparece "Configuración guardada correctamente" y la ventana queda abierta para seguir con las otras pestañas. Validaciones: "Debe seleccionar un tipo de impuesto", "Debe seleccionar un tipo de cálculo", "La fecha de inicio es obligatoria".

Las pestañas Métodos y Subgrupos se habilitan recién cuando la configuración está guardada. Si intentás usarlas antes, el sistema avisa "Debe guardar la configuración primero…".

Pestaña Métodos por Tipo de Bien

Permite que el impuesto se calcule distinto según el tipo de producto (tipo de bien) o la condición fiscal. Estos métodos reemplazan la configuración general para los casos que indiquen.

Con + Agregar Método se abre la ventana Método de Cálculo por Tipo de Bien:

CampoPara qué sirve
Tipo de Bien *Un tipo de producto, o "-- APLICA A TODOS LOS TIPOS DE BIEN --".
Condición FiscalOpcional; vacío aplica a todas.
Base de CálculoNeto gravado, Total factura, Importe exento, Monto fijo, o "Usar base por defecto".
Alícuota (%)Tasa a aplicar.
Mínimo ImponibleMonto por debajo del cual no se aplica.
Monto FijoImporte fijo, si corresponde.
Vigencia Desde * / HastaPeríodo de validez del método.

Cada método de la lista se puede editar o eliminar (pide confirmación: "¿Eliminar método?"). No puede haber dos métodos para el mismo tipo de bien y condición fiscal: "Ya existe una configuración para este tipo de bien y condición fiscal".

Pestaña Subgrupos de Comprobantes

Indica en qué comprobantes se aplica este impuesto. Con + Asignar Subgrupo elegís un subgrupo de comprobantes (por ejemplo "Facturas de proveedores") y tocás Asignar. Cada subgrupo asignado se puede quitar con su botón de desasignar ("¿Desasignar subgrupo?").

Si una configuración no tiene subgrupos asignados, no se aplica en ningún comprobante.

Flujo completo

  1. Verificá que existan el tipo de impuesto, la jurisdicción y la cuenta contable.
  2. + Agregar → completá la Configuración General → Guardar Configuración.
  3. Si el cálculo cambia según el tipo de producto, cargá los Métodos.
  4. En Subgrupos de Comprobantes, asigná los subgrupos donde se aplica.
  5. Probá cargando un comprobante de ese subgrupo y revisá que el impuesto aparezca.
