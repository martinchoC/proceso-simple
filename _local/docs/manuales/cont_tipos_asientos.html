¿Para qué sirve?

Cada asiento contable lleva un tipo que indica de dónde salió: los asientos que cargás a mano en Asientos Contables son siempre del tipo "Asiento Manual"; los que genera el sistema al confirmar comprobantes llevan el tipo que corresponde a su origen. Esta pantalla es la lista de esos tipos. Normalmente se configura una sola vez y casi no se toca.

La pantalla principal

ColumnaQué muestra
IDNúmero interno.
CódigoCódigo corto del tipo.
Tipo de AsientoNombre del tipo.
DescripciónExplicación opcional.
Origenmanual o automatico.
Módulo OrigenTexto libre que indica el área de donde proviene (Ventas, Compras, etc.).
EstadoActivo (fila verde) o Inactivo (fila roja).
AccionesBotones según el estado.

Debajo de cada título de columna hay una cajita "Filtrar..." para filtrar por esa columna. Arriba tenés el selector de cantidad de registros, el buscador general, el botón ↻ de recarga y los botones para exportar a Excel, PDF, CSV o imprimir.

Agregar o editar un tipo

El botón + Agregar abre la ventana Nuevo Tipo de Asiento Contable; el lápiz de una fila abre la misma ventana para editar.

CampoPara qué sirve
Código *Código corto (hasta 20 caracteres). No puede repetirse en la empresa.
Tipo de Asiento *Nombre (hasta 100 caracteres).
DescripciónOpcional.
OrigenManual o Automático.
Módulo OrigenOpcional, por ejemplo "Ventas" o "Compras".
EstadoActivo o Inactivo.

Al tocar Guardar aparece "Tipo de asiento guardado correctamente". Errores posibles: "El código es obligatorio", "El tipo de asiento es obligatorio", "El código ya existe para esta empresa".

Activo e Inactivo

Activo
⇄
Inactivo

Un tipo Activo está disponible para usarse. Uno Inactivo queda dado de baja pero no se borra: los asientos que ya lo usan no cambian. Se puede volver a activar cuando quieras.

Botones disponibles

BotónQué haceCuándo aparece
+ AgregarCrea un tipo nuevo.Siempre.
Editar (lápiz azul)Modifica el tipo.Activo.
Inhabilitar (círculo con cruz, rojo)Pasa el tipo a Inactivo, previa confirmación.Activo.
Habilitar (círculo con tilde, verde)Lo vuelve a Activo, previa confirmación.Inactivo.

Preguntas frecuentes

PreguntaRespuesta
¿Puedo elegir el tipo cuando cargo un asiento manual?No. Los asientos manuales se cargan siempre como "Asiento Manual".
¿Qué pasa si inactivo un tipo que usan asientos existentes?Nada con esos asientos: conservan su tipo. Antes de inactivar un tipo automático, consultá con el equipo, porque puede usarlo el sistema al generar asientos.
