Manual de usuario: Comprobantes Fiscales

La lista oficial de comprobantes de ARCA (ex AFIP) con su código: 001 Facturas A, 006 Facturas B, 011 Facturas C, etc.

¿Para qué sirve?

Cada comprobante con validez fiscal tiene un código oficial. El sistema lo usa para pedir el CAE a ARCA, para saber qué letra corresponde y para decidir qué tipos ofrecer al facturar. Ejemplos de la lista:

CódigoComprobante fiscal
001FACTURAS A
003NOTAS DE CREDITO A
006FACTURAS B
008NOTAS DE CREDITO B
011FACTURAS C
019FACTURAS DE EXPORTACION
Los códigos los fija ARCA: no los cambies. En general esta tabla sólo se toca para habilitar o deshabilitar comprobantes que la empresa usa o deja de usar.

La pantalla principal

El listado muestra ID, Código, Comprobante Fiscal, Estado y Acciones, con buscador, recarga ↻ y menú Exportar.

Agregar o editar

CampoPara qué sirve
Código *Número de 0 a 255, el código oficial de ARCA.
Comprobante Fiscal *Nombre, hasta 50 caracteres.

Si el código o el nombre ya existen: "Ya existe un comprobante con este código o nombre".
