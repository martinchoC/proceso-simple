¿Qué productos se cargan acá?

Esta pantalla es para los productos con stock: la mercadería que se compra, se guarda en el depósito y se vende (por ejemplo, repuestos).

Los conceptos sin stock (servicios, fletes, gastos, honorarios) se cargan en Productos - Generales. Si querés solo consultar datos y precios sin riesgo de modificar nada, usá Productos - Consulta.

Pasos para cargar un producto completo

  1. Con + Agregar, cargá los datos de la pestaña Información y hacé clic en Guardar.
  2. Buscá el producto en el listado y abrilo con Editar (lápiz).
  3. Completá las demás pestañas: Compatibilidad, Imágenes, Ubicaciones, Proveedores y Precios.
Las pestañas Compatibilidad, Imágenes, Ubicaciones, Proveedores y Precios funcionan sobre un producto ya guardado. En un producto nuevo sus botones no hacen nada hasta que lo guardes y lo vuelvas a abrir con Editar. Cada cosa que agregás en esas pestañas se guarda en el momento, sin necesidad del botón Guardar general.

Stock mínimo y máximo por boca

Dentro de la pestaña Información hay una tabla con una fila por cada boca a la que tenés acceso: muestra el stock actual y te deja cargar el Mínimo y el Máximo.

  • Si el stock de una boca queda por debajo del mínimo, el sistema genera una alerta de reposición.
  • Si dejás el mínimo vacío, esa boca no se controla. Para cargar un máximo hay que cargar también el mínimo.
  • El punto de color indica: verde = en nivel, rojo = bajo el mínimo, gris = sin control.

Se guarda junto con el producto. Si los números no tienen sentido (mínimo negativo, máximo menor que el mínimo, máximo sin mínimo), el sistema avisa con "Stock mínimo / máximo" y te lleva a la pestaña para corregir. Si el producto se guardó pero los niveles no, ves "Producto guardado" con el detalle, y la ventana queda abierta para corregir.

Pestaña: Compatibilidad

Indica con qué vehículos es compatible el producto. Es lo que permite encontrarlo filtrando por marca y modelo.

  • + Agregar: abre una ventana para elegir Marca *, Modelo * (se habilita al elegir marca), Submodelo (opcional, o "Sin submodelo"), Año Desde * y Año Hasta (vacío o "Actual" = hasta hoy).
  • Agregar varias: escribí en el buscador (por ejemplo "ford fiesta"), hacé clic en los resultados para sumarlos a la lista "Seleccionadas para agregar", ajustá los años de cada una y hacé clic en Guardar todas.
  • Cada fila tiene botones para editar o eliminar. Eliminar pide confirmación ("¿Eliminar Compatibilidad? Esta acción no se puede deshacer").

Pestaña: Imágenes

Con Agregar Imagen subís una foto (JPG, PNG, GIF o WebP, hasta 5 MB), con descripción, si es la principal y el orden. Se ve una vista previa antes de guardar.

Podés arrastrar las imágenes para cambiar el orden; la primera es la principal. Cada imagen tiene opciones para editarla, marcarla como principal o eliminarla (las dos últimas piden confirmación).

Pestaña: Ubicaciones

Indica en qué lugar del depósito está guardado el producto. Puede tener varias ubicaciones, incluso en distintas sucursales.

  • Agregar Ubicación: elegís una ubicación ya existente bajando nivel por nivel (Sucursal → Boca → Sección → Estantería → Estante → Posición). Al completar, aparece "Ubicación seleccionada" y se habilita Guardar.
  • Nueva Ubicación: si la ubicación todavía no existe, la creás acá mismo (sucursal, boca, sección, estantería, estante, posición y descripción). Al crearla, el sistema pregunta si querés asignarla al producto.
  • Cada fila tiene botones para cambiarla o eliminarla (pide confirmación).

Las ubicaciones se administran en general en Depósitos - Ubicaciones.

Pestaña: Proveedores

Con Agregar Proveedor elegís un proveedor y, opcionalmente, el código con el que ese proveedor identifica el producto. Un producto puede tener varios proveedores, cada uno con su código. Ese código después sirve para buscar el producto desde el filtro "Código o cód. proveedor".

Pestaña: Precios

Muestra el precio del producto en cada lista: precio unitario, precio con IVA y fecha de actualización.

  • Agregar Precio: elegís la Lista de Precios y cargás el Precio Unitario (neto, sin IVA). No puede haber dos precios del mismo producto en la misma lista.
  • Al editar un precio, la lista no se puede cambiar: si te equivocaste de lista, eliminá el precio y cargalo en la correcta.

Para cargar o actualizar precios de muchos productos a la vez (incluso desde Excel), usá Listas de Precios - Productos. Las listas en sí se crean en Listas de Precios - Seteo.

Si alguien usa "Recalcular Precios" en una lista (ver Listas de Precios - Seteo), los precios cargados a mano en esa lista se reemplazan por los calculados.

Para ver los inactivos, cambiá el filtro de estado de arriba.

Exportar, imprimir y catálogo offline

El menú Exportar ofrece Excel, PDF, CSV e Imprimir (del listado tal como lo estás viendo), y además Catálogo Offline & Enviar Email, que abre en otra pestaña la generación del catálogo para enviar. El botón ↻ recarga la tabla.
