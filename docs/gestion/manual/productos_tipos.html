¿Para qué sirve?

Cada producto pertenece a un tipo. El tipo dice cómo se comporta: si lleva control de stock, si es un producto compuesto por otros, si se factura, y qué cuentas contables le corresponden por defecto en compras, ventas y costo de mercadería vendida.

La pantalla principal

ColumnaQué muestra
CódigoCódigo del tipo (en mayúsculas).
TipoNombre.
Stock / Compuesto / FacturaSí o No para cada característica.
Cta. Compra / Cta. Venta / Cta. CMVCuentas contables por defecto.
ProductosCuántos productos usan este tipo.
EstadoActivo o Inactivo (filas inactivas en gris).
AccionesBotones según el estado.

Junto al botón Agregar hay un desplegable para filtrar por estado: al abrir la pantalla muestra sólo los Activos; elegí "Todos los estados" para ver también los inactivos. A la derecha: buscador, recarga ↻ y menú Exportar.

Agregar o editar un tipo

+ Agregar abre la ventana Nuevo Tipo de Producto; el lápiz de una fila la abre para editar.

CampoPara qué sirve
Código *Hasta 20 caracteres; se pasa a mayúsculas solo. No puede repetirse.
Nombre *Hasta 100 caracteres. No puede repetirse en la empresa.
Maneja stockSi está activado, los productos de este tipo llevan control de existencias.
Es compuestoEl producto se arma con otros productos (kit o combo).
Afecta facturaciónViene activado. Indica que los productos de este tipo se facturan.

Al guardar aparece "Tipo de producto creado correctamente" (o "actualizado"). Errores posibles: "Ya existe un tipo de producto con el código …" o "… con el nombre …".

Cuentas contables por defecto

En la sección Cuentas contables por defecto elegís la cuenta de compra, de venta y de CMV (costo de mercadería vendida; sólo se aplica a productos que controlan stock). Cualquiera puede quedar en "(Sin cuenta)".

Estas cuentas se copian al producto en el momento de darlo de alta. Cambiarlas acá no modifica los productos que ya existen: esos hay que corregirlos desde la pantalla de productos.
